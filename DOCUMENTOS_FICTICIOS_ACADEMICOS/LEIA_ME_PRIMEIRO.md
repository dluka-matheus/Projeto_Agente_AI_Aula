# DOCUMENTOS FICTÍCIOS - INSTITUTO HORIZONTE

Esta pasta contém os **12 documentos acadêmicos inteiramente simulados** do projeto integrador de Aplicações Avançadas de IA.
São dados didáticos; nenhum prazo, política ou requisito aqui representa uma instituição real.

## Como usar
- **Para leitura:** abra `Documentos_Academicos_Ficticios.pdf` (também disponível em Word).
- **Para RAG em Python:** carregue `base_conhecimento_academica.json`.
- **Para ingestão de documentos individuais:** carregue os 12 arquivos `.md` desta pasta.
- Em cada documento, preserve o ID em `fonte` ou outro metadado para citar a origem.
